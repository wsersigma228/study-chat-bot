# Scope and possible next steps

The current repository contains archive import, optional collection, deterministic text projections, restricted bot responses, owner homework review and channel publication state.

Future work should start from a concrete failing case and keep a reproducible synthetic example. Broader language understanding, OCR, document extraction and LLM integration are not implemented. Do not present them as available features or add speculative infrastructure for them.

Live Telegram setup and verification must use private configuration supplied by the operator. The synthetic example cannot validate a real source group.
