# Synthetic examples

Every file in this directory contains invented demonstration data. Names, IDs, timestamps, lesson rooms, assignments and attachment references do not describe real people or a real chat.

`desktop-export.json` uses the Telegram Desktop JSON shape for the offline importer. Referenced unavailable attachments deliberately have no shipped media. The fixture illustrates recognized English text and uncertainty; it does not establish live Telegram behavior.

Do not replace these fixtures with a private export. Keep user exports and local media under private/ and out of Git.
